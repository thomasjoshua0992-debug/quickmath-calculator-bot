# 🧮 QuickMath Telegram Bot

QuickMath is a free Telegram mathematics bot built with Python.

It can perform calculations, solve equations, and handle common mathematical functions.

## ✨ Features

- Basic arithmetic
- Powers
- Square roots
- Trigonometric functions
- Logarithms
- Algebra equations
- Direct calculations
- `/start` command
- `/help` command
- `/calculate` command

## 🧮 Examples

Send:

`25 + 75`

The bot returns:

`100`

You can also send:

`x + 5 = 12`

The bot solves the equation.

## 🚀 Commands

`/start`

Start the bot.

`/help`

Show available features.

`/calculate 25 * 4`

Calculate an expression.

## 🛠️ Technologies

- Python
- python-telegram-bot
- SymPy
- python-dotenv

## 🔐 Environment Variable

The bot requires:

`BOT_TOKEN`

Add your Telegram bot token as an environment variable on your hosting platform.

Never publish your real Telegram bot token on GitHub.
